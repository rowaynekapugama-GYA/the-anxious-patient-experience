The Anxious Patient Experience: logo files for PayPal (11 November 2026)

Made from the approved website logo (the navy tile with the cream and taupe wordmark). There is no vector original
in the brief, so these are exported from the 512 px master; the white-background and transparent wordmark versions
are a derived "navy on light" version of the same artwork and should be checked by Lorna before wider use.

Which file goes where in PayPal
- Business logo (Account settings > Business information, or the logo prompt when you customise checkout):
  ape-logo-square-1000.jpg (navy tile on white). If PayPal asks for something smaller, ape-logo-square-250.jpg.
- Checkout header / page style, if your account still shows "Custom payment pages": ape-logo-header-750x90.png
  (750 x 90 is PayPal's header limit) or ape-logo-190x60.png (the small logo slot).
- Anything else that wants a wide logo: ape-logo-horizontal-1200x400.jpg (or the .png with a clear background).
- Anything that wants a small square: ape-logo-square-250.jpg.

The logo shown to patients at checkout is set inside the PayPal account, not by the website. The website only passes
the business name ("The Anxious Patient Experience") and the booking reference with each payment.

Colours: navy #284858, taupe #8F7455, cream #FCFCF6.
